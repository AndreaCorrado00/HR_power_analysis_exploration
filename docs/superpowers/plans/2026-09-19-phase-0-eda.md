# Phase 0 FIT EDA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and run a reproducible EDA of the linked FIT activities and deliver a visually verified PDF without dataset splits, model fitting, or externally parameterized metrics.

**Architecture:** A focused `power_hr_eda` package decodes FIT messages into session and record tables, calculates auditable descriptive quality metrics, creates stable figures, and assembles a ReportLab PDF. One CLI orchestrates immutable FIT inputs into tracked tables and PDF plus untracked images.

**Tech Stack:** Python 3, fitdecode, pandas, NumPy, Matplotlib, ReportLab, pytest, pdfplumber, pypdf, Poppler.

**Spec:** `exploration/2026-09-19-phase-0-eda-design.md`

## Global Constraints

- Never modify files under `dataset/raw/only_road_activities/`.
- Use only FIT values or values deterministically derived from them.
- Exclude FTP-, threshold-, zone-, TSS-, IF-, TRIMP-, fatigue-, form-, recovery-, fueling-, and hydration-dependent metrics.
- Create no training, validation, or test split.
- Do not resample, interpolate, filter, repair, or delete observations.
- Treat lag analysis as descriptive and never shift either signal.
- Ignore `exploration/images/`; track the PDF, tables, source, tests, design, and plan.
- The PDF has no conclusions section and no causal or physiological claims.
- Justify body text and prevent clipping or overlap of titles, captions, tables, and images.

## Review Focus

- Corrupt FIT: retain an inventory row with the parse error and continue.
- No record messages: report zero records and unavailable signal metrics.
- Irregular timestamps: quantify duplicate, negative, and positive intervals separately.
- Only power or HR: retain the session and mark joint diagnostics unavailable.
- Sparse or constant signals: return undefined diagnostics explicitly and avoid division by zero.
